# Aanchal Raj — Portfolio

A static HTML/CSS/JavaScript portfolio inspired by the editorial cream + terracotta theme from the supplied reference image.

## Files

- `index.html` — portfolio structure/content
- `style.css` — complete responsive styling
- `script.js` — mobile navigation, reveal animations and active navigation
- `assets/` — place certificate files/images here if you want to add them later

## Run locally

Simply double-click `index.html` to open it in a browser.

## GitHub

Create a public repository and upload all files/folders. GitHub supports uploading files directly through the browser.

## Vercel

Import the GitHub repository into Vercel. This is a static HTML/CSS/JS site and does not require npm.

Content in this portfolio is based on the supplied CV. No formal internship has been invented; the Internship section is presented as an opportunity/next-step section.
